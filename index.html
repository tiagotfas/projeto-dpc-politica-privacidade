Política de Privacidade — Projeto DPC

Aplicativo de organização, registro e acompanhamento de estudos.

Última atualização: 5 de outubro de 2026

Esta Política de Privacidade explica como o Projeto DPC trata as informações utilizadas durante o uso do aplicativo.

1. Identificação do aplicativo

Aplicativo: Projeto DPC

Desenvolvedor: Projeto DPC

Contato de privacidade:tiagotfas@gmail.com

2. Informações tratadas pelo aplicativo

O Projeto DPC foi desenvolvido para permitir que o usuário organize e acompanhe sua preparação para concursos. Dependendo dos recursos utilizados, o aplicativo pode armazenar no dispositivo informações como:

  • nome informado pelo usuário para personalização da experiência;
  • sessões de estudo, incluindo matéria, tipo de estudo, duração, data e informações registradas pelo usuário;
  • tarefas e informações de planejamento inseridas pelo usuário;
  • preferências de configuração, como tema e meta de estudos;
  • informações necessárias para manter o funcionamento das funcionalidades do aplicativo;
  • informações relacionadas à compra ou à verificação de acesso às funcionalidades Premium, quando o usuário realizar uma compra pelo Google Play.

3. Armazenamento dos dados de estudo

Os dados de estudo e de configuração são armazenados localmente no dispositivo do usuário, no armazenamento interno utilizado pelo aplicativo.

O Projeto DPC não mantém, por conta própria, uma conta de usuário ou um servidor próprio para sincronizar o histórico de estudos.

4. Backup e restauração

O aplicativo permite que o usuário exporte um arquivo de backup e, posteriormente, importe esse arquivo para restaurar seus dados.

O arquivo de backup é criado a partir de uma ação do usuário e pode ser salvo no local escolhido pelo próprio usuário.

O Projeto DPC não recebe nem hospeda esse arquivo.

O usuário é responsável pelo local escolhido para armazenar o backup e pela proteção do arquivo contra acesso não autorizado.

5. Google Play e funcionalidades Premium

O Projeto DPC pode oferecer funcionalidades Premium mediante compra única realizada por meio do Google Play.

O processamento do pagamento é realizado pela infraestrutura do Google Play. O aplicativo utiliza os mecanismos disponibilizados pelo Google Play para verificar o estado da compra e liberar as funcionalidades correspondentes.

O Projeto DPC não solicita nem armazena diretamente dados de cartão de crédito, débito ou outros dados financeiros completos utilizados no pagamento.

6. Compartilhamento de informações

Os dados de estudo armazenados localmente pelo aplicativo não são vendidos nem compartilhados pelo Projeto DPC com terceiros para fins de publicidade ou marketing.

Quando aplicável, informações relacionadas às compras e à licença Premium podem ser processadas pela infraestrutura do Google Play de acordo com as políticas e práticas de privacidade do Google.

7. Anúncios

O Projeto DPC não contém anúncios publicitários.

8. Contas e login

O Projeto DPC não exige que o usuário crie uma conta dentro do aplicativo para utilizar seus recursos de estudo.

9. Permissões e acesso ao dispositivo

O aplicativo utiliza os recursos necessários ao funcionamento de suas funcionalidades. O acesso a arquivos para exportação ou importação de backups ocorre mediante as ferramentas do sistema Android e por ação do usuário.

10. Segurança

Os dados de estudo mantidos pelo aplicativo são armazenados no armazenamento interno do aplicativo no dispositivo.

O Projeto DPC adota medidas técnicas compatíveis com o funcionamento do Android para evitar acesso casual aos dados por outros aplicativos.

Nenhum método de armazenamento eletrônico é absolutamente seguro. O usuário também deve proteger o próprio dispositivo e os arquivos de backup que decidir exportar.

11. Retenção e exclusão de dados

Os dados de estudo permanecem no dispositivo enquanto forem mantidos pelo usuário ou pelo aplicativo.

O usuário pode utilizar os recursos de gerenciamento de dados disponíveis no aplicativo, incluindo a opção de limpar os dados e a possibilidade de remover o aplicativo do dispositivo.

Arquivos de backup exportados pelo usuário podem permanecer no local escolhido pelo usuário mesmo após a remoção do aplicativo. Esses arquivos devem ser excluídos pelo próprio usuário quando não forem mais necessários.

12. Privacidade de crianças

O Projeto DPC não é direcionado especificamente a crianças.

O aplicativo é destinado a pessoas que estejam se preparando para concursos públicos e não solicita informações pessoais de crianças para criação de contas.

13. Alterações nesta Política

Esta Política de Privacidade poderá ser atualizada quando houver mudanças relevantes no aplicativo, nas funcionalidades oferecidas ou nas práticas de tratamento de dados.

A versão atualizada será disponibilizada nesta mesma página, com a respectiva data de atualização.

15. Ciência

Ao utilizar o Projeto DPC, o usuário declara estar ciente desta Política de Privacidade e das práticas nela descritas.
